# FLECKY Demo v0.3.0 — A living icy bay

## Скачать / Download

Распакуйте `FLECKY_Demo_0.3.0_Windows.zip` целиком и запустите `FLECKY.exe`.
Windows 10/11 x64; установка Godot и интернет для игры не нужны.

Extract the entire ZIP and run `FLECKY.exe`. No Godot installation required.

## Что нового

- Новая модель Флэки с плавными формами, мягкими ластами и изогнутыми усами.
- Обновлённая вода: волны, отражения, преломление, солнечный свет под водой и мягкая каустика.
- Естественный рельеф дна, новые материалы камней и песка, валуны и ленточные водоросли.
- Цельная скальная пещера и собственная модель осьминога с движущимися щупальцами.
- Пещера теперь служит укрытием: акула ждёт снаружи и уходит; ранний выход возобновляет погоню.
- Неровные льдины с неглубокой, хорошо заметной подводной частью.
- Новые материалы основных рыб с сохранением исходных анимаций.
- Объёмные фоновые стайки с индивидуальными движениями хвостов.
- Новая модель краба; походка, угроза и танец на голос Флэки сохранены.

## Highlights

A rebuilt seal, natural seabed and cave, improved ice and underwater lighting,
an original octopus, refreshed fish and a new crab mesh using the existing animations.
The octopus cave now protects Flecky from shark bites.

The ten-fish objective, free swimming after victory, achievements and RU/UK/EN
localization remain. Controls: WASD, mouse, Space/Ctrl, Shift, E, F, V and Esc.
